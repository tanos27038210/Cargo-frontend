## Фронтенд

React (Vite) + React Router + Axios.

### Запуск

1. Запустите бэкенд (порт 8081).
2. Перейдите в папку фронтенда: `cd cargo-crm-frontend`
3. Создайте файл `.env`:
   ```
   VITE_API_URL=http://localhost:8081/api
   ```
4. Установите зависимости и запустите:
   ```
   npm install
   npm run dev
   ```
5. Откройте http://localhost:5173 и войдите тестовым пользователем.

Адрес фронтенда должен быть в списке `cors.allowed-origins` бэкенда.

### Страницы

- Вход, Dashboard (сводка), список клиентов и страница клиента с его заказами
- Список заказов (поиск, фильтры, сортировка, страницы) и страница заказа:
  посылки, смена статуса с допустимыми переходами, история статусов, сообщения
- Управление пользователями (только администратор)
- Страницы «Не найдено» и «Доступ запрещён», адаптивная вёрстка и мобильное меню

## Дополнительные правила

- Заказ в статусе `DELIVERED` или `CANCELLED` изменять нельзя, добавлять в него посылки тоже
- Менеджер изменяет и пишет сообщения только в своих заказах, администратор в любых
- Пользователей не удаляют, а деактивируют; администратор не может отключить себя и сменить себе роль
